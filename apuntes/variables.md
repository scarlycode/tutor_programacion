# Variables

Una variable es un nombre que guarda un valor en la memoria del programa. En Python se crea al asignarle un valor con el signo igual.

Ejemplo: edad = 15 guarda el número 15 en una variable llamada edad. Después puedes usar edad en otras operaciones.

Los tipos básicos son int (enteros), float (decimales), str (texto) y bool (verdadero o falso). Python detecta el tipo automáticamente según el valor.

Buenas prácticas: usa nombres claros y en minúsculas, como nombre_usuario, y evita empezar con números o usar espacios.
